# 🔐 Password Generator

A responsive Password Generator website built using **HTML, CSS, and JavaScript**. Generate random passwords with customizable lengths and character types, copy them instantly, and switch between light and dark themes.

## 🌐 Live Demo

**[Click here to try the Password Generator](https://sanjaycodes045.github.io/PasswordGenerator/)**

##  Features

-  Generate random passwords instantly.
-  Customize password length from 4 to 32 characters.
-  Include uppercase and lowercase letters.
-  Include numbers and special symbols.
-  Copy passwords to the clipboard with one click.
-  Switch between dark mode and light mode.
-  Save theme and password length preferences using `localStorage`.
-  Responsive design for different screen sizes.
-  Validation when no character type is selected.

##  Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome
- Clipboard API
- Web Storage API (`localStorage`)

## 📖 How to Use

1. Select your preferred character types.
2. Adjust the password length using the slider.
3. Click **Generate Password**.
4. Click **Copy** to copy the generated password.
5. Use the theme toggle to switch between light and dark modes.

Your selected theme and password length are remembered after refreshing the page.
